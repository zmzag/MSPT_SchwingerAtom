# MSPT_SchwingerAtom
Applying multi-scale perturbation theory techniques to 1+1d QED problems

This takes in a Schwinger atom steady state classical soliton generated with the choice of a particular g,\kappa.  This code then solves for the quadratic 
eigenenergies and eigenfunctions, calculates the Lamb shift, and calculates the dynamics due to the lowest order interaction terms.
